# Kabankalan Catholic College, Inc. | Landing Page

Project 2 (egca-project-2): a one-page landing page for Kabankalan Catholic College, Inc.,
built on the layout of the [Mentor](https://bootstrapmade.com/mentor-free-education-bootstrap-theme/)
Bootstrap template by BootstrapMade.

> Student project for coursework. This is not the official website of Kabankalan Catholic College, Inc.

Author: John Cris G. Egca

## Sections

Hero, About, Statistics, Vision and Mission, Academic Levels, College Programs, Core Values,
History timeline, Call to Action and Contact (with map).

## Structure

```
egca-project-2/
├── index.html
└── assets/
    ├── css/main.css
    ├── js/main.js
    └── img/        school seal, campus photo, program images
```

Bootstrap, Bootstrap Icons and AOS are loaded from the jsDelivr CDN, so an internet connection is needed to see the full styling.

## Run locally

Open `index.html` in any browser. No build step needed.

## Content notes

Facts about the school (founding in 1927, the Columban Fathers, levels offered, Senior High School tracks,
college programs, vision, mission and core values) come from public pages. Please verify them against
the school's official materials before using this page for anything other than coursework.
The illustrations are original drawings, not the school's official logo or photos.
